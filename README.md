# 📄 Extrator Inteligente de Currículos (AI Builder Portfolio)

Ferramenta desenvolvida para automatizar a triagem e estruturação de currículos desestruturados utilizando Engenharia de Prompts Avançada e conceitos de IA aplicada a negócios.

## Sobre o Projeto
Este projeto faz parte do portfólio para a trilha de **AI Builder**, demonstrando a capacidade de transformar problemas de RH em fluxos automatizados eficientes, sem a necessidade de backends complexos.

## Tecnologias e Conceitos Utilizados
- **Frontend / Prototipagem:** HTML5, CSS3, JavaScript (Vanilla).
- **Prompt Engineering:** Estruturação de dados baseada em blocos rígidos (Contato, Objetivo, Formação Acadêmica, Cursos e Informações Extras) com restrições de formato (JSON/Blocos).
- **Deploy:** Replit & GitHub Pages.

## Como Acessar
Você pode testar a aplicação rodando diretamente no ar através do link de preview do Replit ou clonando este repositório.
